# Navita

Unofficial build of [Kavita](https://github.com/Kareadita/Kavita) (latest stable release), not affiliated with the Kavita project. For everything else see the official [Kavita](https://github.com/Kareadita/Kavita) and [docs](https://wiki.kavitareader.com).

## Changes

- Book reader, scroll layout: footnote and other anchor links now scroll to the target, and back links return to the reference instead of the start of the chapter.
